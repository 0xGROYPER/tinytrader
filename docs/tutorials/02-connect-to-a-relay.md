# Connect to a relay

Read live market data from a relay in your own program, as DBN records.

See [Write a strategy as a client](strategy-client.md#2-market-data-from-a-relay): joining a relay, replaying from a start time, and reading the records in Rust or Python. The protocol and the relay's HTTP endpoints are in the [market data relay API](../api/relay.md); why it works this way is in [decision 0006](../decisions/0006-market-data-relay.md).
