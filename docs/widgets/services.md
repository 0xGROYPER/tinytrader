# Services

Every service with its container state, health, uptime, restarts and resources,
and under the heading the tools the deployment runs beside tinytrader: each of
the topology's `links` (an `http` or `https` URL) by its name, opened in a new
tab. A deployment's batch scheduler's UI goes here, for example
(`"links": {"jobs": "http://scheduler.example:4646/ui/jobs"}`).

**Data:** Docker (read only, through docker-proxy), each service's health, and
the topology's `links`.
