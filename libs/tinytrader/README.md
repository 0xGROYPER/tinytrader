# tinytrader

Simple tools for trading on financial markets: market data relays, a data store, and a console,
built on [Databento's DBN format](https://databento.com/docs/standards-and-conventions/databento-binary-encoding).

This crate is the entry point. It currently re-exports [`tinytrader-dbn`](https://crates.io/crates/tinytrader-dbn),
tinytrader's DBN extensions; more libraries follow as they're published.
